## Decisions
- D-001: Create job p99 latency target is 200 ms and status p99 target is 50 ms.
- D-002: Migration p99 duration targets are 600 seconds intra-region and 3600 seconds cross-region.
- D-003: Migration success rate target is 99.9 percent and blast-radius cap is 100 tenants per job.
- D-004: Every transition emits trace context, structured logs, and audit ids per ADR-0217.
- D-005: Protocol fallback, Cedar deny, pack mismatch, and rollback are first-class SLI labels with bounded cardinality.
