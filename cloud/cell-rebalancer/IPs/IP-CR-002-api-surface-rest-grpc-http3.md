## Decisions
- D-001: OpenAPI 3.2.0 is the first contract surface for the five ADR-0276 endpoints.
- D-002: OperationIds include date version and reserved proto3 tag 8001 carrier naming.
- D-003: api-gateway owns the external date URL prefix while this service preserves ADR-0276 /v1 paths.
- D-004: HTTP/3 over QUIC is default and fallback events are observable under ADR-0209.
- D-005: Every state-changing operation embeds Cedar pre-evaluation and audit-chain emission shape.
