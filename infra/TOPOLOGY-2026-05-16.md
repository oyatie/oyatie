## Storage policy

Per user directive 2026-05-16 ('larger storage on-prem; distribute load'):

- **Large-state / append-only** stays on-prem ZFS bulk (`oyatie-bulk` pool, 3.5 TB, sanoid-snapshotted):
  - `/srv/oyatie/audit-chain`        — audit-chain primary
  - `/srv/oyatie/openbao/data`       — OpenBao file storage (new dataset)
  - `/srv/oyatie/regional-packs`     — regional packs
  - `/srv/oyatie/object-graph`       — knowledge graph
  - `/var/lib/oyatie/{cells,outbox,index}` — workspace-shell cell state
- **Cold off-site backup** on OCI Object Storage Archive tier (10 GB Always Free):
  - `axdotp9iv3ua/oyatie-audit-cold-backup` — audit-chain DR mirror
- **Stage-0 ephemeral** on OCI instances (boot vol + tmp):
  - `oyatie-stage0`: app shell working state (re-derivable)
  - `oyatie-e2-*`: bastion + ops local state (re-derivable)

## OpenBao topology (per ADR-0043, applied to KR cell pair)

- **Primary** (this on-prem host): single-node Wave 1; file storage on
  `/srv/oyatie/openbao/data` (ZFS dataset, copies=2, compression=zstd);
  Shamir 5/3 unseal; audit log to `/srv/oyatie/audit-chain/openbao-audit.jsonl`;
  systemd-hardened unit; CAP_IPC_LOCK.
- **Secondary** (A1 stage0 VM): performance replica via Raft join, Wave 2.
- **HSM auto-unseal** (Thales Luna 7 KR / KCMVP + FIPS 140-3): Wave 3 / production.
- **HA cluster of 3-5 nodes per cell**: Wave 4 / production.

## On-prem bring-up — single command

Everything is now tracked under `infra/onprem/` and orchestrated by one script:

```
sudo bash /home/oyatie/projects/oyatie/infra/onprem/setup.sh
```

Idempotent. Re-runs are safe. Phases:

| # | Path | What |
|---|---|---|
| 1 | `hardening/install.sh` | sysctl, ZFS scrub, smartmontools, fail2ban, journald cap, BBR |
| 2 | `sanoid/install.sh` | ZFS snapshot schedule (audit-chain, regional-packs, openbao, ...) |
| 3 | `reboots/install.sh` | weekly restart timers |
| 4 | `foundry/install.sh` | Foundry workspace-shell systemd cell (`oyatie.service`) |
| 5 | `openbao/install.sh` | OpenBao Wave-1 (file storage on ZFS, Shamir 5/3 seal) |
| 6 | `podman/install.sh` | Rootless container runtime |
| 7 | `containerd/install.sh` | containerd 2.3.0 LTS + runc 1.4.0 + CNI 1.6.0 |
| 8 | `kubeadm/install.sh` | k8s 1.35 (iptables-legacy pinned + nft flush for Debian 13) |
| 9 | `istio/install.sh` | Istio 1.29.2 + Envoy |
| 10 | `cloudflared/setup-cloudflared.sh` | tunnel daemon (token from tofu) |
| 11 | `diagnose.sh` | full health report (no-sudo capable) |

Two scripts that complement `setup.sh`:

- `infra/onprem/diagnose.sh` — exhaustive health check, 10 sections, GREEN/RED per check. Runnable as the unprivileged user.
- `infra/onprem/tarball/install-from-tarball.sh` — installs prebuilt binary from a release tarball (CI-published path).
- `infra/onprem/build/build-all-targets.sh` — cross-compiles the workspace-shell binary for all release targets.

All of these were previously in `/home/oyatie/` and are now versioned in the repo. The home-directory copies remain as a compatibility seam.
