# SDK Plan: Supply Chain Planning

## A. SDK surfaces
SDKs are generated from OpenAPI 3.2.0 and proto3 contracts, with event helper bindings generated from AsyncAPI 3.1.0. Each SDK enforces tenant_id, idempotency_key, residency_pack, and audit_event_class fields before request dispatch.

## B. Language roster
- rust: typed client, retry policy, error taxonomy, and signed payload helper.
- typescript: typed client, retry policy, error taxonomy, and signed payload helper.
- python: typed client, retry policy, error taxonomy, and signed payload helper.
- go: typed client, retry policy, error taxonomy, and signed payload helper.
- java: typed client, retry policy, error taxonomy, and signed payload helper.
- kotlin: typed client, retry policy, error taxonomy, and signed payload helper.
- swift: typed client, retry policy, error taxonomy, and signed payload helper.
