# IP-004: Workflow Template Library

Status: Reconciled
Date: 2026-05-21

## Goal

Provide deterministic templates for lab and pathology workflows.

## Templates

- Lab order intake and accessioning.
- Lab result verification, release, correction, and cancellation.
- Pathology case accessioning, grossing, diagnosis draft, sign-out, amendment, and addendum.
- Critical-result notification and acknowledgement.
- Reflex-test evaluation and follow-up lab order request.

## Acceptance

- Workflow templates have deterministic state transitions and audit events.
- No imaging acquisition, modality worklist, or radiology worklist template exists in diagnostics.
