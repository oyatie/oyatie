# IP-001: Layer-A Postgres + Citus + Valkey + ClickHouse + workflow-runtime IaC

## Intent

Author Helm + Kustomize manifests for the full Layer-A stack (Postgres + Citus / Valkey Sentinel HA / ClickHouse / workflow-runtime deployment) under `microservices/workflow-engine/iac/helm/`. Deploys to the engine cluster per ADR-0131 and `multi-region.md`. Versions pinned to LTS per `docs/standards/workflow-engine-substrate.md` §"Layer-A components".

## ChangeSet boundary

One cohesive ChangeSet: 4 Helm chart bundles (Postgres+Citus, Valkey, ClickHouse, workflow-runtime) + Kustomize base + per-pack overlay for pack-kr. No code; pure IaC + values. Per-pack secret references via OpenBao. OtherBC adapters' configuration (Postgres connection pools, Valkey Sentinel endpoints, ClickHouse cluster discovery) is generated by this IP's templates.

## Code Shape

Helm chart skeleton example (`postgres/values.yaml`):

```yaml
postgres:
  image:
    repository: citusdata/citus
    tag: "12.1-pg16"  # LTS pin per docs/standards/workflow-engine-substrate.md
  coordinator:
    replicas: 2  # HA primary + standby
    persistence:
      size: 200Gi
      storageClassName: oci-bv-fast
  worker:
    replicas: 4  # XS tier per capacity-model.md
    persistence:
      size: 200Gi
      storageClassName: oci-bv-fast
  citus:
    enable_2pc: true  # for cross-shard transactional consistency
    shard_count: 32
  secrets:
    postgres_password:
      valueFrom:
        secretKeyRef:
          name: openbao-postgres
          key: password
```
