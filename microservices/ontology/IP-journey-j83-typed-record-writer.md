# IP-journey-j83-typed-record-writer - ontology

## Goal

Implement the `typed-record-writer` slice for `ontology` so j83 can satisfy `CN-PIPL-2021` without leaking tenant data, collapsing provider-BYOK and encryption-BYOK meanings, or bypassing Cedar.

## PRD row alignment

- PRD anchor: microservices/ontology/PRD.md when present, otherwise the service manifest and architecture surface for that microservice.
- Journey anchor: docs/user-journeys/j83-cn-pipl-data-localization-and-cac-assessment/.
- Regulator article focus: PIPL Art 28 sensitive personal information.
- Rigor row: documentation-rigor.md section 2 IP row; one service, one single-PR-sized implementation plan.

| File | Purpose | Notes |

| `microservices/ontology/contracts/openapi/j83-typed-record-writer-v1.yaml` | OpenAPI 3.2.0 REST surface | External read/write or admin action |

| `microservices/ontology/runbooks/j83-typed-record-writer-rollback.md` | Rollback and incident path | Includes regulator deadline handling |
| `microservices/ontology/tests/j83_typed_record_writer_test.rs` | Integration tests | Positive, negative, rollback, audit |

## Data model

Primary object: `cn-pipl-cac-assessment` with tenant_id, subject_id, pack_id, jurisdiction_code, purpose, data_class, deadline_at, byok_provider_ref, byok_encryption_ref, and prior_seal_ref.
The service may store a local projection only when it can be rebuilt from the audit-chain and source-of-truth service. Mutable state must carry tenant_id and data_class.

## Cedar fragment

```cedar
permit (principal is Principal, action == Action::"j83.ontology.typed-record-writer", resource is JourneyObject) when {
  principal.tenant_id == resource.tenant_id &&
  resource.pack_overlay == "CN-PIPL-2021" &&
  context.jurisdiction == "CN" &&
  context.data_class_allowed == true &&
  context.audit_chain_required == true
};
```
