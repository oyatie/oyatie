# IP-001: Layer-A Grafana OSS stack IaC

## Intent

Author Helm + Kustomize manifests for the full Grafana OSS observability stack (Alloy + Prometheus + Mimir + Loki + Tempo + Pyroscope + Grafana + Alertmanager + Grafana OnCall) under `microservices/observability/iac/helm/`. Deploys to the dedicated observability Kubernetes cluster per ADR-0130 Layer-A and `multi-region.md`. Versions pinned to LTS per `docs/standards/observability-slo.md` §"Grafana stack components".

## ChangeSet boundary

One cohesive ChangeSet: 9 Helm chart bundles (one per OSS component) + 1 shared Kustomize base + per-pack Kustomize overlays for the active packs (pack-kr at M01 launch). No code; pure IaC + values. Per-pack secret references via OpenBao (no raw secrets in repo). The otel-ingest BC's configuration (Alloy collector config per-µservice) is generated by this IP's templates.

## Code Shape

Helm chart skeleton example (`mimir/values.yaml`):

```yaml
mimir:
  fullnameOverride: mimir
  global:
    image:
      registry: docker.io
      repository: grafana/mimir
      tag: "3.3.0"  # LTS pinned per docs/standards/observability-slo.md
  multitenancy_enabled: true
  limits:
    max_global_series_per_user: 1000000  # per /specs §mimir_multi_tenancy production tier
    ingestion_rate: 100000
    cardinality_analysis_enabled: true
  blocks_storage:
    backend: s3
    s3:
      endpoint: "${oci_object_storage_endpoint}"
      bucket_name: "${oci_mimir_bucket}"
      secret_access_key: "${openbao:secret/observability/mimir/s3-secret}"
  alertmanager:
    enabled: true
  ruler:
    enabled: true
    rule_path: /etc/mimir/rules
```

## Test Plan

- Per Phase-01 §"Per-IP Test Coverage Threshold" IaC class: ≥ 1 helm-install + helm-test smoke per chart; 1 against kind/k3d cluster.
- Test files: `microservices/observability/tests/iac/{alloy,mimir,loki,tempo,pyroscope,grafana,alertmanager,oncall,alloy}.bats` (bats-core) running `helm install --dry-run` + `helm test`.

## Halt Conditions

- Any chart upstream-version drift from the LTS pin — escalate to docs/standards/observability-slo.md PR.
- OpenBao secret-reference resolution failure — block; engage cloud-secrets µservice.
- kind cluster smoke fails — root-cause; do not mask.
