# IP-journey-j82-telemetry-and-slo - observability

## Goal

Implement the `telemetry-and-slo` slice for `observability` so j82 can satisfy `KR-FSS` without leaking tenant data, collapsing provider-BYOK and encryption-BYOK meanings, or bypassing Cedar.

## PRD row alignment

- PRD anchor: microservices/observability/PRD.md when present, otherwise the service manifest and architecture surface for that microservice.
- Journey anchor: docs/user-journeys/j82-kr-fss-financial-fraud-24h-freeze/.
- Regulator article focus: Electronic Financial Transactions Act KR fraud response.
- Rigor row: documentation-rigor.md section 2 IP row; one service, one single-PR-sized implementation plan.

## Files to author in the implementation PR

| File | Purpose | Notes |
|---|---|---|
| `microservices/observability/contracts/openapi/j82-telemetry-and-slo-v1.yaml` | OpenAPI 3.2.0 REST surface | External read/write or admin action |
| `microservices/observability/contracts/asyncapi/j82-telemetry-and-slo-events-v1.yaml` | AsyncAPI 3.1.0 event surface | Emits ADR-0263 events |
| `microservices/observability/contracts/proto/j82-telemetry-and-slo-v1.proto` | proto3 internal RPC | Service-to-service call path |
| `microservices/observability/policy/j82-telemetry-and-slo.cedar` | Cedar permit/forbid bundle | Deny-wins gate |
| `microservices/observability/runbooks/j82-telemetry-and-slo-rollback.md` | Rollback and incident path | Includes regulator deadline handling |
| `microservices/observability/tests/j82_telemetry_and_slo_test.rs` | Integration tests | Positive, negative, rollback, audit |

## Data model

Primary object: `kr-fss-fraud-freeze` with tenant_id, subject_id, pack_id, jurisdiction_code, purpose, data_class, deadline_at, byok_provider_ref, byok_encryption_ref, and prior_seal_ref.
The service may store a local projection only when it can be rebuilt from the audit-chain and source-of-truth service. Mutable state must carry tenant_id and data_class.

## Cedar fragment

```cedar
permit (principal is Principal, action == Action::"j82.observability.telemetry-and-slo", resource is JourneyObject) when {
  principal.tenant_id == resource.tenant_id &&
  resource.pack_overlay == "KR-FSS" &&
  context.jurisdiction == "KR" &&
  context.data_class_allowed == true &&
  context.audit_chain_required == true
};
```
