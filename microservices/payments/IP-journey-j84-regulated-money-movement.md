# IP-journey-j84-regulated-money-movement - payments

## Goal

Implement the `regulated-money-movement` slice for `payments` so j84 can satisfy `JP-APPI` without leaking tenant data, collapsing provider-BYOK and encryption-BYOK meanings, or bypassing Cedar.

## PRD row alignment

- PRD anchor: microservices/payments/PRD.md when present, otherwise the service manifest and architecture surface for that microservice.
- Journey anchor: docs/user-journeys/j84-jp-appi-elder-user-consent/.
- Regulator article focus: JP APPI cross-border transfer consent.
- Rigor row: documentation-rigor.md section 2 IP row; one service, one single-PR-sized implementation plan.

| File | Purpose | Notes |
|---|---|---|
| `microservices/payments/contracts/openapi/j84-regulated-money-movement-v1.yaml` | OpenAPI 3.2.0 REST surface | External read/write or admin action |
| `microservices/payments/contracts/asyncapi/j84-regulated-money-movement-events-v1.yaml` | AsyncAPI 3.1.0 event surface | Emits ADR-0263 events |
| `microservices/payments/contracts/proto/j84-regulated-money-movement-v1.proto` | proto3 internal RPC | Service-to-service call path |

| `microservices/payments/runbooks/j84-regulated-money-movement-rollback.md` | Rollback and incident path | Includes regulator deadline handling |
| `microservices/payments/tests/j84_regulated_money_movement_test.rs` | Integration tests | Positive, negative, rollback, audit |

## Data model

Primary object: `jp-appi-elder-consent` with tenant_id, subject_id, pack_id, jurisdiction_code, purpose, data_class, deadline_at, byok_provider_ref, byok_encryption_ref, and prior_seal_ref.
The service may store a local projection only when it can be rebuilt from the audit-chain and source-of-truth service. Mutable state must carry tenant_id and data_class.

## Cedar fragment

```cedar
permit (principal is Principal, action == Action::"j84.payments.regulated-money-movement", resource is JourneyObject) when {
  principal.tenant_id == resource.tenant_id &&
  resource.pack_overlay == "JP-APPI" &&
  context.jurisdiction == "JP" &&
  context.data_class_allowed == true &&
  context.audit_chain_required == true
};
```
