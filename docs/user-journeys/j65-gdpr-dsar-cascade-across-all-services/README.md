## Journey Summary
- Persona: An EU resident exercising GDPR Article 15 and Article 20 rights
- Scenario: a DSAR cascades through eleven service surfaces with proof preservation and transparent export
- Center of gravity: `workflow-engine`
- Services: `workflow-engine`, `identity`, `tenancy`, `mail`, `messenger`, `drive`, `payments`, `community`, `marketplace`, `compliance`, `audit-chain`
- Marketplace settlement is treated as the commercial authority for tenant deals.
- The dual-tenant identity boundary stays explicit and mechanically testable.
- Conglomerate parent-child hierarchy follows ADR-0313 and does not widen personal-data access.
- Community, where present, blends TeamBlind anonymity expectations, Reddit discussion gravity, LinkedIn professional graph, and Handshake recruiting flows.

## Integration Points
- `workflow-engine` / `dsar-orchestration`: durable state-machine plus DAG orchestration with deterministic replay.
- `identity` / `subject-verification`: passkey identity, SCIM, audience type, Cedar principal context, recovery.
- `tenancy` / `tenant-scope-resolution`: tenant provisioning, dual-tenant boundary, child tenant hierarchy, data residency.
- `mail` / `mail-export`: inbound and outbound mail, DKIM/SPF/DMARC, JMAP/SMTP, action-card delivery.
- `messenger` / `message-export`: work and personal conversations, incident notifications, support threads.
- `drive` / `file-export`: evidence storage, write-once archive, labels, imaging, and export packages.
- `payments` / `receipt-export`: Stripe Connect, marketplace settlement, refunds, dunning, disputes, payouts.
- `community` / `community-export`: TeamBlind + Reddit + LinkedIn + Handshake mixture for reputation and reviews.
- `marketplace` / `order-export`: tenant deal settlement, order surfaces, seller-buyer mediation, revenue split.
- `compliance` / `gdpr-pack`: pack overlays, regulator clocks, SOC2/HIPAA/PCI/GDPR evidence packages.
- `audit-chain` / `dsar-proof`: Merkle seal, non-repudiation, chain-of-custody, immutable audit rows.

## Contract Rules
- REST: OpenAPI 3.2.0.
- Events: AsyncAPI 3.1.0.
- Workers and streams: proto3.
- Policy grammar references: BNF v4.1.
- Architecture vocabulary: ADR-0105 13-layer.
- Layout: flat per-µservice IP file under ADR-0131.
- Transport: HTTP/3 + TLS 1.3 + ECH + PQC hybrid where supported, with graceful fallback.
