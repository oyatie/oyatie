# j109-construction-co-hires-freelance-specialist - Integration test plan

Purpose: prove that ConstructionCo Sydney posts a three-month specialist contract through Community Handshake-mode, runs
interview and e-sign through workflow-engine, verifies insurance, and pays milestones.

## Test environment

- Test tenants: tenant-constructionco-sydney, b2c-specialist-ravi-menon.
- Test clock: deterministic HLC with per-region skew injection.
- Test policy: Cedar default-deny loaded first; permits are published after signature verification and soak.
- Test data: synthetic, non-production, no secrets, no live rails.
- Test contracts: OpenAPI 3.2.0, AsyncAPI 3.1.0, proto3, JSON Schema 2020-12.
