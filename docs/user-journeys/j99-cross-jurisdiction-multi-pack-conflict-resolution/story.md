# j99 Story - Cross-jurisdiction multi-pack conflict resolution

## Cold open

Marcus Chen starts from a real product pressure point: Marcus operates EU, US, KR, and AU footprints where one user data path triggers four packs and the higher-restriction floor wins.
The platform must preserve identity continuity, tenant scoping, and pack-aware controls while higher restriction floor + transparency report carries the user from first action to regulator-ready evidence.

## Persona continuity

- P99 evidence sealing target is 2 s with audit-chain local WAL fallback and retry until Merkle anchor.

- Multi-region behavior is pack-specific: a sovereign-cell obligation wins over latency preference.
