# j99 Handshake - Cross-jurisdiction multi-pack conflict resolution

## Phase 0 - Precondition contract

- Pack set: EU-GDPR, US-CCPA, KR-PIPA, AU-PRIVACY-ACT.
- Cell set: eu-sovereign, us-ccpa-ready, kr-csap, au-irap-protected.
- Conflict rule: The selected obligation is the strictest applicable one per field, action, destination, and retention window; operator override is not a permit source.
- Governance has signed the pack fragment bundle and policy-engine evaluates deny-wins.
- Audit-chain root is current before any irreversible state transition.

## Sequence overview

```
Marcus Chen -> api-gateway -> identity -> tenancy -> workflow-engine -> compliance -> governance -> cell -> audit-chain -> observability
workflow-engine -> 45 microservice fanout -> gather -> evidence bundle -> user/regulator receipt
```

- Mutating calls use idempotency key `journey_id + tenant_id + phase + service + attempt`.

- Cell migration pauses external traffic, drains queues, replays accepted events in destination cell, then switches DNS/ingress only after audit parity.
- Regulator evidence is partitioned by article reference so one regulator never receives another jurisdiction's restricted subject content.
