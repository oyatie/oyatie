# j93 Handshake - India DPDPA and RBI financial overlay for Aiyana

## Phase 0 - Precondition contract

- Pack set: IN-DPDPA-2023, IN-RBI-PAYMENTS.
- Cell set: in-sovereign, rbi-payment-evidence-ready.
- Conflict rule: RBI payment-tier controls override convenience checkout and DPDPA consent withdrawal blocks downstream analytics immediately.
- Governance has signed the pack fragment bundle and policy-engine evaluates deny-wins.
- Audit-chain root is current before any irreversible state transition.

## Sequence overview

```
Aiyana Rao -> api-gateway -> identity -> tenancy -> workflow-engine -> compliance -> governance -> cell -> audit-chain -> observability
workflow-engine -> 45 microservice fanout -> gather -> evidence bundle -> user/regulator receipt
```
