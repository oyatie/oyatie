# j96 Story - KSA and UAE MENA tenant onboarding

## Cold open

Marcus Chen starts from a real product pressure point: A Saudi enterprise tenant onboards into a sovereign KSA cell with Arabic UX while UAE PDPL data flows remain separately governed.
The platform must preserve identity continuity, tenant scoping, and pack-aware controls while tenant onboarding + Arabic locale UX carries the user from first action to regulator-ready evidence.
