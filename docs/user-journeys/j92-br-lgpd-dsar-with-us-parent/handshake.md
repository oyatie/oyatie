# j92 Handshake - BR LGPD DSAR with US parent overlap for Tomas

## Phase 0 - Precondition contract

- Pack set: BR-LGPD, US-CCPA, EU-GDPR.
- Cell set: br-sovereign, us-parent-restricted, eu-transfer-reviewed.
- Conflict rule: LGPD response honors CCPA/GDPR where they are stricter and refuses a parent-company shortcut when BR-LGPD requires clearer subject notice.
- Governance has signed the pack fragment bundle and policy-engine evaluates deny-wins.
- Audit-chain root is current before any irreversible state transition.

## Sequence overview

```
Tomás Silva -> api-gateway -> identity -> tenancy -> workflow-engine -> compliance -> governance -> cell -> audit-chain -> observability
workflow-engine -> 45 microservice fanout -> gather -> evidence bundle -> user/regulator receipt
```
