# j91 Handshake - US state money transmitter licensing for Yejin

## Phase 0 - Precondition contract

- Pack set: US-MSB, US-CA-MTL, US-NY-MTL, US-TX-MTL, US-FL-MTL, US-WA-MTL.
- Cell set: us-general, us-financial-services, state-mtl-evidence-ready.
- Conflict rule: Payment flows fail closed once any state threshold is reached without an active MTL or permitted agent-of-payee exemption.
- Governance has signed the pack fragment bundle and policy-engine evaluates deny-wins.
- Audit-chain root is current before any irreversible state transition.

## Sequence overview

```
Yejin Park -> api-gateway -> identity -> tenancy -> workflow-engine -> compliance -> governance -> cell -> audit-chain -> observability
workflow-engine -> 45 microservice fanout -> gather -> evidence bundle -> user/regulator receipt
```
