# Integration Test Plan — j51-procure-to-pay-po-extraction-and-approval

## 1. Claim Under Test
The j51 bundle is complete when the journey can be simulated across all listed µservices with tenant isolation, Cedar default-deny, OpenAPI/AsyncAPI/proto contract validation, audit-chain emission, and rollback evidence.

## 2. Test Environment
Use one enterprise tenant, one personal tenant for the same human when applicable, one counterparty tenant, and one regulator or provider sandbox tenant when applicable.
Seed identity with passkey principals, SCIM membership where applicable, role overlays, and explicit audience type values.
Seed tenancy with home cell, DR-pair, compliance packs, conglomerate parent-child hierarchy where applicable, and data-residency constraints.
Seed OpenBao SecretReference values for third-party provider credentials; tests must never place raw secrets in fixtures.
Seed marketplace deal state for any commercial handoff; marketplace is the settlement authority even when payments moves funds.
Contract convention under test: OpenAPI 3.2.0, AsyncAPI 3.1.0, proto3, BNF v4.1, ADR-0105 13-layer, ADR-0131 flat layout, HTTP/3, ECH, and PQC.
