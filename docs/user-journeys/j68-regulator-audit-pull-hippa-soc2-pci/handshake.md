# Handshake — j68-regulator-audit-pull-hippa-soc2-pci

## 1. Handshake Invariant
Every edge in this sequence carries tenant context, principal context, audience type, data class, purpose, idempotency key, Cedar decision, and audit event class.
No service calls a PSP, IdP, mail provider, postal API, or other vendor with raw credentials. Provider access goes through OpenBao SecretReference and the library-first credential sidecar.
The sequence uses OpenAPI 3.2.0 for REST, AsyncAPI 3.1.0 for event channels, proto3 for internal streaming or worker calls, and BNF v4.1 for policy grammar references.
HTTP/3 is the preferred transport. QUIC-blocked networks fall back to HTTP/2 then HTTP/1.1; TLS 1.3, ECH, certificate transparency, OCSP stapling, and PQC negotiation are declared at every ingress.

## 2. Sequence
```
01. identity [scoped-read] -> workflow-engine [tenant-scoped contract + audit context]
02. workflow-engine [audit-routing] -> drive [tenant-scoped contract + audit context]
03. drive [evidence-pack] -> audit-chain [tenant-scoped contract + audit context]
04. audit-chain [seal-service] -> observability [tenant-scoped contract + audit context]
05. observability [dashboard-share] -> compliance [tenant-scoped contract + audit context]
06. compliance [per-pack-attestation] -> ops-dashboard-control-center [tenant-scoped contract + audit context]
07. ops-dashboard-control-center [auditor-console] => audit-chain [tenant-scoped contract + audit context]
```
