# Feature-Flag Architecture — Oyatie

> **Status:** Accepted. **Owner:** `axis-foundry`. **Date:** 2026-05-12.

## 1. Standard: OpenFeature

[OpenFeature](https://openfeature.dev/) is the CNCF-incubating vendor-neutral flag SDK. We adopt it as the **single in-tree flag API**. Per [Directive 4](../../plans/MASTERPLAN.md) (provider-agnostic), every flag-provider integration lives in an adapter crate behind the OpenFeature `Provider` interface. Application code never imports a provider SDK directly.

This mirrors the existing Foundry adapter pattern ([ADR-0020](../../../docs/decisions/ADR-0709-general-live-apex.md)).

## 2. Kernel + adapter layout

- `platform-feature-flag-kernel` (existing-or-NEW per workspace audit) — OpenFeature core: evaluation, targeting, audit-chain emit, cohort intersection.
- `platform-feature-flag-api` (NEW) — typed flag definitions, evaluation surface, SDK exports.
- `platform-feature-flag-adapter-launchdarkly` (NEW) — LaunchDarkly OpenFeature provider.
- `platform-feature-flag-adapter-growthbook` (NEW) — GrowthBook OpenFeature provider.
- `platform-feature-flag-adapter-flagsmith` (NEW) — Flagsmith OpenFeature provider.
- `platform-feature-flag-adapter-unleash` (NEW) — Unleash OpenFeature provider.
- `platform-feature-flag-adapter-inhouse` (NEW) — in-house evaluation (default; zero-egress for regulated tenants).

Swap a provider = change one workspace dep. No call-site rewrites. **Final shape on day one** per [Directive 3](../../plans/MASTERPLAN.md).

## 3. Flag taxonomy

| Type | Purpose | Default lifetime | Owner | Audit class |
|---|---|---|---|---|
| **Release** | Hide incomplete work; canary-gated rollout | ≤ 90 days post-stable | feature-team | release |
| **Experiment** | A/B / cohort experiment | ≤ 60 days; auto-conclude on power | product-data | experiment |
| **Kill-switch** | Cut a feature in a Sev-1 | indefinite (audited annually) | on-call lead | ops |
| **Permission** | Per-tenant / per-persona entitlement | indefinite (drives Cedar policy) | identity-axis | permission |
| **Operational** | Per-cell / per-region behaviour toggle | indefinite | platform-axis | ops |

A flag MUST declare its `type:` in its TOML registration. `governance-feature-flag-debt` refuses untyped flags.

## 4. Lifecycle (release-class)

```
create (PR + flag registration)
   ↓
rollout (canary stages drive flag enablement)
   ↓
stable (100% on; flag remains for kill-switch fallback)
   ↓
retire (≤ 90 days post-stable: auto-PR removes flag + dead branch)
```

Auto-PR is generated by `governance-feature-flag-debt` when a stable flag exceeds the 90-day budget. PR contains the flag-removal diff + dead-branch removal. Lane is HIGH severity (escalates to BLOCKER at 180 days).

## 5. Flag-debt budget

Per axis: ≤ 25 active release-class flags simultaneously; ≤ 5 stable-and-not-retired older than 90 days; **0** older than 180 days. Excess emits PR-blocking lane finding.

## 6. Cohort intersection

Every flag evaluation is intersected with the tenant's cohort (per [`stable-cohort-spec.md`](stable-cohort-spec.md)). A release-class flag set to 25% canary still returns `false` for stable-cohort tenants. Intersection is enforced in the kernel, not the adapter — adapters cannot bypass.

## 7. Audit-chain emission

Every flag flip emits a D14 audit-chain record ([ADR-0003](../../../docs/decisions/ADR-0709-general-live-apex.md)): `who`, `which flag`, `what value`, `targeted cohort`, `timestamp`, `signed-commit-hash`. Flips during incident response are tagged `incident_id`. No anonymous flips.

## 8. Hyperscaler equivalents

- LaunchDarkly + Split.io (commercial standard).
- AWS AppConfig (in-house; CodeDeploy-integrated).
- Microsoft Azure App Configuration (1ES-integrated).
- Google internal "Mendel" / Cloud Run flag (not externally exposed; OpenFeature is the export).
- Oracle OCI Resource Manager flags (limited).

All accessible behind the OpenFeature provider interface; we adopt OpenFeature as the wire.

## 9. Anti-scope

Flag UI / admin console is owned by `platform-feature-flag-app` (NEW; separate plan). This doc owns the kernel/contract.

## 10. Compliance gates

- `governance-feature-flag-debt` (NEW; HIGH at 90 days, BLOCKER at 180 days).
- `governance-cohort-honor` (NEW; HIGH).
- `governance-audit-emit` (existing; extended to cover flag flips).
