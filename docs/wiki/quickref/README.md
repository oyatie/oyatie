# Oyatie wiki quick reference

> **Owner:** `council-architecture`.
> **Status:** Bootstrap baseline.
> **Purpose:** Keep the documentation-system storage map grounded while the internal wiki is still represented in-repo.

This directory is the checked-in quick-reference seed for future internal wiki pages named by [`docs/DOCUMENTATION.md`](../../DOCUMENTATION.md). It is not a parallel canonical authority tree: canonical product, architecture, governance, and runbook authority stays in `docs/` and its catalogued documents.

When a new quick-reference page is added here:

1. Link to the canonical source document instead of copying policy text.
2. Name the owning team in the page header.
3. Keep the page short enough to serve as lookup, not narrative documentation.
4. Update `registry/docs/pipeline.tsv` if the page changes the documented wiki/docs generation pipeline.
