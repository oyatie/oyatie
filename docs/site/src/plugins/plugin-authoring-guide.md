# Plugin authoring guide

Plugins extend approved surfaces without bypassing tenant policy, evidence capture, or capability
publication rules. Authors declare the capability contract first, then wire the runtime adapter. Authoritative plugin authoring and marketplace rules live in [`docs/standards/plugin-authoring.md`](../../../standards/plugin-authoring.md) and [`docs/products/saas-platform/PRD.md`](../../../products/saas-platform/PRD.md); this guide is navigation-only and makes no live-readiness claim.

For user-facing composition, see the [Workflow Studio guide](../studio/workflow-studio-guide.md).
