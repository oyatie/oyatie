# Workflow Studio guide

Workflow Studio is the user-facing workspace for composing approved capabilities into repeatable
workflows. The studio shows autonomy tier, evidence status, and data use boundaries before a flow is
run. Authoritative product and API boundaries live in [`docs/products/saas-platform/PRD.md`](../../products/saas-platform/PRD.md) and [`docs/api/workflow-studio-api-reference.md`](../../api/workflow-studio-api-reference.md); this guide is navigation-only and makes no live-readiness claim.

A workflow can call published capabilities from the [first capability tutorial](../tutorials/first-capability.md).
