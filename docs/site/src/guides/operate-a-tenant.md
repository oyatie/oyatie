# Operate a tenant

Tenant operators manage identity, capability grants, cost ceilings, and evidence review from one
administrative surface. Every tenant action stays inside the data use boundary and cell isolation
contracts.

For the conceptual model, see the [cohesion thesis](../concepts/cohesion-thesis.md). For the user
surface, continue to the [tenant administration guide](../admin/tenant-admin-guide.md).
