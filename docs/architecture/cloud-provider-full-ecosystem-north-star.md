# Cloud provider + full ecosystem north-star

**Authority:** This file survives the product spine for agents loading `docs/**`. Programme execution detail and phase Done-when live in the living N=1 programme tracker (Cursor plan `domain_stack_integ_model` § *Cloud provider + full ecosystem capacity*). **BAN** a second architecture `.plan.md`. **BAN** treating compute-only wedges as the product goal.

## Binding locks (2026-08-11)

1. **Not compute-only.** Oyatie ships **entire cloud-provider capacity** — hyperscaler-parity and broader over time (IaaS → classic PaaS → progressive CSP catalog).
2. **Full curated ecosystem.** Infra → platform → enterprise productivity/verticals → consumer on **one owned substrate** — broader than typical hyperscaler cohesion (not broker glue; not Azure+M365 bolt-on adjacency as the model).
3. **One service, not multi-provider marketplace.** EU/EuroStack multi-provider supply is the *problem class* and an *aligned reference* for open contracts / exit; oyatie’s *delivery shape* is one curated cohesive ecosystem.
4. **EU / SECA named because they align with what cloud ought to look like** (interop, residency-as-capability, designed exit) — **not** because “EU checklist” is the programme driver.
5. **Selective refuse:** **MUST NOT** adopt jurisdiction decisions that add end-user friction for excessive personal-data sovereignty theater at UX cost. Defaults plug-and-play; advanced residency/control is opt-in; jurisdiction packs are overlays.
6. **Retention:** transparency + ethics + economics (Rust efficiency) + product good enough — **BAN** bait-and-switch lock-in.
7. **Contracts:** SECA-capable (and open) faces in **Rust**; smooth **entry and exit**.

## Two tracks (phased)

| Track | Scope | First slice |
| --- | --- | --- |
| **A — CSP capacity** | Control plane → network/storage/images → VM / managed k8s / bare metal / GPU → managed DB / queues / LB-DNS / object+CDN → catalog expansion | Phase 0: durable registry + operations + reconciler + tenant/IAM + SECA pin |
| **B — Ecosystem products** | `app/<product>/**` per-product integ rails (office, CRM/ITSM, healthcare FLAT, …) on shared IAM/tenancy/cells/policy | Parallel under rail rules; sellable CSP demos gate on A0→A1 |

## Lane split

- **PRODUCTIZED:** control-plane APIs, provision adapters, SECA/open SDK, reusable PaaS surfaces.
- **OYA_SPECIFIC:** cell/Cedar/jurisdiction packs and curated SKU composition — namespaced, minimal.
- Ephemeral agent/session kits are **not** product.
