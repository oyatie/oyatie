# Declaration Reconciliation Generated-Buck V1 contract

This is the closed, code-owned `ReindeerBuckV1` validator contract adopted only for Build L1d-L1g. It is neither a general compilation-unit, semantic-fact, conformance, codemod, recipe, repository-input, campaign, Storage, Data, nor cross-owner schema; a request supplies exact facts, never grammar, rule, attribute, expression, callee, bound, or failure policy. K validates fixture bytes only; A may use fixture configuration; F may report the current stale face; D alone materializes and replaces it; Q qualifies it. No dual header exists.

## Fixed profile

The only accepted prefix bytes are:

```text
# @generated by `reindeer buckify`

load("@prelude//rust:cargo_buildscript.bzl", "buildscript_run")
load("@prelude//rust:cargo_package.bzl", "cargo")

```

The prefix includes its blank separators; the custom deleted-overlay header is stale and nonconforming. Admission also requires `split=false`, `file_name=BUCK`, `third_party_metadata=false`, and exact bound generator source, lock, and binary identities. A changed header, import, callee, or schema is a V2 transition, not request policy.

| Semantic role | Only callee |
|---|---|
| alias / alias-with-platforms | `alias` |
| Rust sources / filegroup | `rust_filegroup` / `filegroup` |
| archives / Git | `http_archive`, `extract_archive` / `git_fetch` |
| Rust library/root / Rust or build-script binary | `cargo.rust_library` / `cargo.rust_binary` |
| build-script run / native / prebuilt native | `buildscript_run` / `cxx_library`, `prebuilt_cxx_library` |

## Exact request expectations and encoding

`GenerationRequestV1.expected_graph: ExpectedGeneratedGraphV1` follows `validator` and is encoded in `request_id` declaration order. It contains fixed `ExpectedPreambleV1` and `RuleCalleeSetV1` (compared with the constants above), plus exact collections of non-alias `ExpectedRuleIdentityV1`, `ExpectedAliasIdentityV1`, `SemanticFactV1`, and `DeclaredExternalV1`.

Rules and aliases share one target namespace. `rules` is a bijection with every non-alias definition; aliases are outside it and have `(name, owner, sort_name, actual, platforms)`, where `actual` is local. Alias compatibility and visibility are facts. Facts are exact, not contains-at-least. Canonical input sorts rules and aliases by target bytes, facts by full typed tuple, and externals by `(label,use_kind)`; a duplicate or unsorted canonical key refuses rather than normalizes. `PackageVersionV1.version` parses as canonical `semver::Version` and equals `to_string()`; K uses the already locked workspace `semver` 1.0.28 only in core `Cargo.toml`/`BUCK` via `third-party//:semver`, never root Cargo or lock. Ordering is parsed SemVer, never lexical.

## Lexical and fact closure

Identifiers are ASCII `[A-Za-z_][A-Za-z0-9_]*` up to 128 bytes; a callee is one identifier or exactly `identifier.identifier`. A local target is ASCII `[A-Za-z0-9_][A-Za-z0-9_.+=,@~-]*`, <=4096 bytes, not `.`/`..`, and has no slash, colon, bracket, or whitespace. A local label is `:target` with optional `[canonical/subtarget/path]`; cells have optional `@` then `[A-Za-z_][A-Za-z0-9_.-]*`; external labels are `//pkg:target`, `cell//pkg:target`, or `@cell//pkg:target` with optional canonical subtarget, with empty package only `//:target`. No spelling, Unicode, label, path, or escape normalization occurs.

Canonical paths reject absolute, UNC, drive-qualified, backslash, empty, dot, dot-dot, and reserved adapter-token (`@stage`, `@repo`, `@cargo-home`, `@empty-home`) components. Attribute schema—not `contains("//")`—classifies path, label, URL, flag, and opaque values. Only the fixed preamble label and typed URL/repository contexts admit absolute-looking strings.

```rust
enum FactScopeV1 { Base, Platform { name }, Select { term, key }, PlatformSelect { platform, term, key } }
enum SelectKeyV1 { Default, Label(BuckLabelV1) }
enum LabelAtomV1 { Internal(LocalLabelV1), External(BuckLabelV1) }
enum SemanticAtomV1 { OpaqueString(String), True, Path(CanonicalPathV1), InternalLabel(LocalLabelV1), ExternalLabel(BuckLabelV1), Location(LocationTemplateV1), EmptyList, EmptyMap }
struct LocationTemplateV1 { prefix, label: LabelAtomV1, suffix }
struct SemanticFactV1 { subject, scope, attribute, map_key: Option<SemanticAtomV1>, ordinal: Option<u64>, value: SemanticAtomV1 }
```

Scope tags are 0..3; `SelectKey`/`LabelAtom` 0..1; `SemanticAtom` 0..7. A nonempty platform/select branch emits `PlatformBranch`/`SelectBranch` with `True`; an empty branch emits `EmptyMap`/`EmptyList`. Ordered sequences use consecutive ordinals, sets none, maps typed keys; absence differs from an emitted empty container.

| Context | Exact schema |
|---|---|
| scalars | crate, crate_root, edition, sha256, strip_prefix, repo, rev, package_name, version, link_style, linkable_alias, preferred_linkage, python_ext, header_namespace, local/target manifest_dir, static_lib, archive src |
| true-only | dlopen_enable, proc_macro, rustc_link_lib, rustc_link_search, undefined_symbols |
| unordered sets | set srcs/exported_headers, features, licenses, deps, headers, sub_targets, visibility |
| ordered sequences | urls, compatible_with, target-compatible select arms, rustc/linker/compiler/preprocessor flags, include directories |
| maps / branches | env, mapped_srcs, named_deps, map srcs/exported_headers; platform dictionaries, select chains, and filegroup glob produce their scoped/presence or ordered GlobInclude/GlobExclude facts |

RuleRef contexts produce typed labels; path-or-label gives a valid label precedence, otherwise requires a canonical relative path. Other strings remain exact opaque facts and any opaque `$(` refuses. Valid single location templates are only env `$(location LABEL)` with optional `/canonical/path`, rustc `@$(location LABEL)`, and preprocessor/include `-I$(location LABEL)` with optional suffix; wrong name, nesting, multiplicity, prefix/suffix, or malformed form refuses. Sha256 is 64 lowercase hex; edition is `2015|2018|2021|2024`; select keys are `DEFAULT`, an exact request platform label, or declared external `SelectCondition`.

Each internal label resolves exactly one parsed definition. Every external label or location edge must match declared `(label,use_kind)`; K declares but never resolves those edges, and D/Q Buck receipts prove existence/configuration.

## Grammar and rule schemas

```ebnf
file = fixed_preamble, definition*, EOF ; definition = callee, "(", LF, attribute+, ")", LF ;
callee = ident | ident, ".", ident ; attribute = indent, ident, " = ", value, ",", LF ;
value = string | "True" | list | map | glob | dict | select_expr ;
glob = "glob(", list, ", exclude = ", list, ")" ; dict = "dict(", named_arguments?, ")" ;
select = "select(", map, ")" ; select_expr = (list | select), (" + ", select)* ;
```

UTF-8/LF only: refuse BOM, CR, NUL, tab, semicolon, trailing material, post-preamble load, non-header comments, assignments, def/lambda/comprehension/conditional/indexing, arbitrary operators/calls, integers/floats/False/None/metadata/tuples. Strings accept only canonical double-quoted `serde_starlark 0.1.19` escapes; redundant/single/raw/triple forms refuse. `[]` and `{}` are empty forms; normal one-element lists are one line, 2+ and forced-common select lists multiline; nonempty maps multiline. Only bounded nested glob/dict/select and list-plus-select forms exist.

| RustFilegroup | name, srcs?, mapped_srcs?, platform?, visibility |

`local_manifest_dir` and `manifest_dir` are exclusive. Attribute presence/order/cardinality, projection, identity, and definition order are exact; the parser never repairs, reorders, or rewrites bytes.

## Bounds, failures, and K acceptance

Bounded streaming permits nesting 16, loads 32, loaded symbols 128, tokens 8,388,608, facts/declared externals/edges 1,000,000, output 64 MiB, stderr 1 MiB, rules 100,000, attributes/rule 512, entries/attribute 131,072, string 1 MiB, diagnostic 8 KiB; every limit+1 refuses. Unsorted request collections refuse.

| Condition | FailureClassV1 |
|---|---|
| malformed tag/UTF-8/path/identity; duplicate/unsorted expectation; request limit+1; profile/generator mismatch | `InvalidRequest` |
| changed admitted external file/tree | `InputChanged` |
| stdout/stderr limit+1 | `GeneratorOutputTooLarge` |
| A/B bytes differ, including same injected digest | `NondeterministicOutput` |
| generated lexical/grammar/schema/order/preamble/import/path/wrapper/bound error; duplicate/dangling/undeclared edge; missing/extra identity/fact | `InvalidGeneratedGraph` |
| proven unreachable core state | `InternalInvariant` |

Tags 0..17 and other adapter/publication mappings do not change. The collision fixture forces equal test-only digests for distinct A/B bytes and requires `NondeterministicOutput`, no validated generation, and zero publisher calls; resident bytes are never deduplicated solely by digest.

K adds only `starlark_lexer.rs`, `starlark_parser.rs`, `generated_graph_contract.rs`, `generated_graph_schema.rs`, `semantic_projection.rs` beside existing core items; `validation.rs` remains orchestration/failure mapping. It adds `tests/{starlark,generated_graph,semantic_projection}.rs` and matching `dependency-declarations-reconcile-{starlark,generated-graph,semantic-projection}-test` targets; no package/library target. K may then change only core Cargo/BUCK, membership test, core scanner fixup, and these item/test files.

K red tests cover arbitrary import/load, callee substitution, extra dependency, unknown/reordered/duplicate attribute, missing/extra alias, alias cycle/dangling actual, escaped duplicate name, local-label-as-path, undeclared external/select key, wrong branch, metadata/int/False/None, nesting/every limit+1, whitespace/order/escape, overlay comment, invalid/nested/multiple location macro, absolute/UNC/drive/backslash/reserved-token path, root-not-last, archive-before-alias, lexical-versus-SemVer, and collision bytes. They prove panic freedom and failure mapping, not A/F/D/Q behavior.
