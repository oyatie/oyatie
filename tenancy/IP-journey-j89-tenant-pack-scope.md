# IP-journey-j89-tenant-pack-scope - tenancy

## Goal

Implement the `tenant-pack-scope` slice for `tenancy` so j89 can satisfy `UK-AADC + UK-Online-Safety-Act` without leaking tenant data, collapsing provider-BYOK and encryption-BYOK meanings, or bypassing Cedar.

## PRD row alignment

- PRD anchor: microservices/tenancy/PRD.md when present, otherwise the service manifest and architecture surface for that microservice.
- Journey anchor: docs/user-journeys/j89-uk-aadc-minor-ux-adaptation/.
- Regulator article focus: UK Age Appropriate Design Code high privacy by default.
- Rigor row: documentation-rigor.md section 2 IP row; one service, one single-PR-sized implementation plan.

## Data model

Primary object: `uk-aadc-minor-ux` with tenant_id, subject_id, pack_id, jurisdiction_code, purpose, data_class, deadline_at, byok_provider_ref, byok_encryption_ref, and prior_seal_ref.
The service may store a local projection only when it can be rebuilt from the audit-chain and source-of-truth service. Mutable state must carry tenant_id and data_class.

## Cedar fragment

```cedar
permit (principal is Principal, action == Action::"j89.tenancy.tenant-pack-scope", resource is JourneyObject) when {
  principal.tenant_id == resource.tenant_id &&
  resource.pack_overlay == "UK-AADC + UK-Online-Safety-Act" &&
  context.jurisdiction == "UK" &&
  context.data_class_allowed == true &&
  context.audit_chain_required == true
};
```
