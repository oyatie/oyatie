# IP-001: Layer-A Grafana OSS stack IaC

## Intent

Author Helm + Kustomize manifests for the full Grafana OSS observability stack (Alloy + Prometheus + Mimir + Loki + Tempo + Pyroscope + Grafana + Alertmanager + Grafana OnCall). The ArgoCD/dev-cell entrypoint is `microservices/observability/iac/k8s/helm/`; component chart modules and production value fragments remain under `microservices/observability/iac/helm/`. Deploys to the dedicated observability Kubernetes cluster per ADR-0139 Layer-A and `multi-region.md`. Versions pinned to LTS per `docs/standards/observability-slo.md` §"Grafana stack components".

## ChangeSet boundary

One cohesive ChangeSet: 1 ArgoCD umbrella chart (`iac/k8s/helm`) that composes the active OSS components for dev-cell bring-up, 9 component chart modules / production value fragments under `iac/helm`, 1 shared Kustomize base, and per-pack Kustomize overlays for the active packs (pack-kr at M01 launch). No code; pure IaC + values. Per-pack secret references via OpenBao (no raw secrets in repo). The otel-ingest BC's configuration (Alloy collector config per-µservice) is generated by this IP's templates. Production promotion must fail closed until SeaweedFS object storage and tenant-scoped datasource provisioning replace any dev-only local backend or dev tenant marker.

## Code Shape

Helm chart skeleton example (`mimir/values.yaml`):

```yaml
mimir:
  fullnameOverride: mimir
  global:
    image:
      registry: docker.io
      repository: grafana/mimir
      tag: "3.3.0"  # LTS pinned per docs/standards/observability-slo.md
  multitenancy_enabled: true
  limits:
    max_global_series_per_user: 1000000  # per /specs §mimir_multi_tenancy production tier
    ingestion_rate: 100000
    cardinality_analysis_enabled: true
  blocks_storage:
    backend: s3
    s3:
      endpoint: "${oci_object_storage_endpoint}"
      bucket_name: "${oci_mimir_bucket}"
      secret_access_key: "${openbao:secret/observability/mimir/s3-secret}"
  alertmanager:
    enabled: true
  ruler:
    enabled: true
    rule_path: /etc/mimir/rules
```

## Halt Conditions

- Any chart upstream-version drift from the LTS pin — escalate to docs/standards/observability-slo.md PR.
- OpenBao secret-reference resolution failure — block; engage cloud-secrets µservice.
- kind cluster smoke fails — root-cause; do not mask.


## DR posture (per ADR-0343)
- Manifest target source: `microservices/observability/manifest.json#dr` is missing; `rto_p99_seconds` and `rpo_p99_seconds` are not invented in this IP.

- Multi-region posture: `multi_region_active_active` is not declared in the manifest; any floor with `multi_region=true` must force active-active before this IP can serve that pack.
