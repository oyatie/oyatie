# IP-journey-j85-clinical-note-boundary - notes

## Goal

Implement the `clinical-note-boundary` slice for `notes` so j85 can satisfy `HIPAA-2024` without leaking tenant data, collapsing provider-BYOK and encryption-BYOK meanings, or bypassing Cedar.

## PRD row alignment

- PRD anchor: microservices/notes/PRD.md when present, otherwise the service manifest and architecture surface for that microservice.
- Journey anchor: docs/user-journeys/j85-hipaa-end-to-end-phi-workflow/.
- Regulator article focus: HIPAA 45 CFR 164.504(e) business associate contract.
- Rigor row: documentation-rigor.md section 2 IP row; one service, one single-PR-sized implementation plan.

## Files to author in the implementation PR

| File | Purpose | Notes |
|---|---|---|
| `microservices/notes/contracts/openapi/j85-clinical-note-boundary-v1.yaml` | OpenAPI 3.2.0 REST surface | External read/write or admin action |
| `microservices/notes/contracts/asyncapi/j85-clinical-note-boundary-events-v1.yaml` | AsyncAPI 3.1.0 event surface | Emits ADR-0263 events |
| `microservices/notes/contracts/proto/j85-clinical-note-boundary-v1.proto` | proto3 internal RPC | Service-to-service call path |

| `microservices/notes/runbooks/j85-clinical-note-boundary-rollback.md` | Rollback and incident path | Includes regulator deadline handling |
| `microservices/notes/tests/j85_clinical_note_boundary_test.rs` | Integration tests | Positive, negative, rollback, audit |

## Data model

Primary object: `hipaa-phi-workflow` with tenant_id, subject_id, pack_id, jurisdiction_code, purpose, data_class, deadline_at, byok_provider_ref, byok_encryption_ref, and prior_seal_ref.
The service may store a local projection only when it can be rebuilt from the audit-chain and source-of-truth service. Mutable state must carry tenant_id and data_class.

## Cedar fragment

```cedar
permit (principal is Principal, action == Action::"j85.notes.clinical-note-boundary", resource is JourneyObject) when {
  principal.tenant_id == resource.tenant_id &&
  resource.pack_overlay == "HIPAA-2024" &&
  context.jurisdiction == "US" &&
  context.data_class_allowed == true &&
  context.audit_chain_required == true
};
```
